# Evaluation language references

Current Calor prompts read the compiler's embedded
`Calor.Compiler.Resources.current-language-reference.md`. There is no separate
Calor skills file or basic-syntax fallback. C# prompts still use
`csharp-language-skills.md` in this directory.

Author Calor constructs, keywords, C# equivalents, examples, primer selections,
agent instructions and MCP catalogs in
`src/Calor.Compiler/Resources/Teaching/reference.json`.

Regenerate with `dotnet run --project src/Calor.Compiler -- self-check docs --fix`,
then rebuild so packaged resources match the generated files. Check without
writing with `dotnet run --project src/Calor.Compiler -- self-check docs`.
The existing documentation mirror check rejects stale or missing output.

Generated consumers include syntax lookup JSON/LSP hover, topic help, the fixed
primer, initialization templates, MCP instructions/catalogs, the E2E reference,
and current evaluation prompts. The generated `current-language` syntax page in
`docs/` and the website is an additional current reference; consolidation of the
remaining public reference pages awaits the final grammar work.

For custom topic-help testing, `CALOR_REFERENCE_FILE` explicitly selects a
Markdown reference. An unreadable override returns an error, never a different
reference. It does not override syntax-query metadata or evaluation prompts.

This infrastructure does not choose final 0.30 spellings or establish token
budgets. Those require the agreed grammar decisions and genuine Anthropic Opus
5.5 `count_tokens` measurements. Historical prompt records and measurements are
not regenerated by this process.
