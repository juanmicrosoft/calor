## Spurious refutations

These are not soundness defects. The frozen vocabulary has no "known incompleteness" value, so each
one is fixed or demoted like any other finding:

- **Fixed:** the model now reaches the obligation, or the claim is proved. This applies to the else
  facts, named-refinement facts, UTF-16 literals, and the Substring range.
- **Demoted:** the obligation is `Unsupported` instead of a `Failed` compile error with a
  counterexample the program cannot produce. This applies to obligations after a reassignment and
  to refined returns.

## R-NUM: decision required (5 findings per baseline)

`NUM-NARROW-ARITH` and `NUM-LITERAL-OVERSIZE` are registered `unsupported-refused`; the frozen
modeled-forms doc lists them as divergences D1 and D2, "refused". `NUM-OVERFLOW-CHECKED` is
registered `assumed`.

The verifier deliberately does something else:

- it models C# narrow promotion (W1 Slice 1);
- it types `INT:` literals the way C# does (#774);
- it proves checked-arithmetic contracts whose preconditions rule out overflow. The row title says
  "unless entailed", but the frozen classification table counts any `Proven` on an `assumed` row.

Every one of these `Proven` results agrees with the oracle; none is a false proof. Under the frozen
table each is still a finding, and `VALIDATED` is not allowed.

A draft that implements the registered refusals is 77 non-test lines. It breaks 19 existing tests
that pin the deliberate semantics, and it changes the committed #1135 differential oracle reports.
Options:

1. Accept the demotion as R-NUM, the sixth and last repair.
2. Make a contract amendment, after decision-bearing inspection, that reclassifies the rows.
3. Record `MILESTONE-FAILED` (terminal predicate 5 then fails).

## Discovery finding outside the registered sweep

**#1493:** on Windows, non-ASCII identifiers can collapse into one Z3 symbol through ANSI marshaling.
This could produce a false proof. It was found by code reading during #1135, was not executed by S1,
and is not part of the registered sweep. Disposition: `FIX-IN-0.24` by R-TEXT (an injective ASCII
symbol encoding). Its end-to-end witness runs on Windows in the z3-consumer-matrix job.
