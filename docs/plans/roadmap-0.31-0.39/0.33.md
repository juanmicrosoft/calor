## Epic #1653 · [0.33] Epic: agent reach

Existing epic #1653. The body below replaces or amends it as marked.

#### Goal

Make Calor a first-class language for every major coding agent (Claude Code, Codex, Gemini and GitHub Copilot) and show it with measurements taken the same way for each.

#### Why

Through 0.32 every agent measurement of Calor is a Claude Code measurement. The pair harness (`bench/phase0-agent-native/run-pair.sh`) starts only the `claude` CLI, and its initialized-workspace mode runs `calor init --ai claude`. `calor init` already writes a setup for four agents, but the four instruction files are byte-identical and are budgeted with one proxy tokenizer. Of the three setups other than Claude Code's, only Codex's has been exercised by its own agent: once, in July 2026 on the pre-0.30 syntax, where the generated write hooks did not fire.

The epic sits after 0.32 because launching earlier would teach agents a language that is about to change. The edition now enforces that reason: 0.33 opens on the edition declared in #1805, or on its recorded deferral. Either way no issue in this epic changes an existing spelling, and whatever each agent reveals about the language is recorded for the re-affirmation in #1846.

#### Work

| #1651 | A driver contract in the pair harness with the Claude Code driver moved behind it, drivers for Codex, Gemini and Copilot, and a zero-cost pass per driver. No spend |

### #1830 · [0.33] Language-neutral, process-level oracle for a small headroom task set

#### Change
