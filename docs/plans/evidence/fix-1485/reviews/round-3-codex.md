Tests: `EmptyDecision_DoesNotSwallowSiblingFunction`, `EmptyContextSection_DoesNotAdoptSiblingSectionFiles`. **This changed a committed fixture:** in `tests/TestData/EditScripts/ES-07-persistent-finding/*/{stable,churn}.calr`, the one-line `§CT "…"` had been swallowing the module's only function. That restores the registered intent: a documented, diagnostic-clean file that is served from cache, next to an undocumented one that is not. |

The last-index check removes the cost whenever no closer follows. |
