## Mechanism

An invocation of a function-typed VALUE — `§C{f}` where `f` is a parameter, a `§B`, a
field, or the result of a call — is no longer Calor0418 `DelegateInvocation`. The value's
effect row is read from the declaration that put it in scope (the same `§E{…}` node the
binder's `FunctionBoundType.Row` was built from; read as the node rather than the bound
projection because `Binder.BindRow` collapses a variable-mentioning row to Unknown and
`f §E{e}` invoked inside a rank-1 `Map` must charge `e`) and charged to the invoking
function inside inference (`EffectInferrer.ChargeInvokedRow`), where every other call is
charged — so it flows through the SCC fixpoint, into a `§LAM`'s ρ_body when the
invocation sits inside a lambda, and into Calor0410 with no extra propagation step.

| Row at the invocation | Charged | Reported |
|---|---|---|
| `Concrete(S)` | `S`, with §10.1's provenance clause for Calor0410 | nothing |
| `Assumed(S, R)` | `S` | one Calor0425 carrying `R` (§4.4) |
| `Unknown` | `EffectSet.Unknown` (fail-closed, as an unknown external call); nothing under `--permissive-effects` | Calor0425 at the invocation (suppressed under the flag) |
| provably not a function (`i32`, `str`, `[T]`) | nothing | **Calor0418, retained for this residual only** — an error under every policy |

Calor0424 is never reported at an invocation: §6.2's site table has no invocation row
because there is no destination row to fit into. The caller's under-declaration is the
ordinary Calor0410.
