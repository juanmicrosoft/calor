## Authority and stop semantics

This is the single shared authority section for the children. The original adoption claim is unchanged:

| Gate | Required original result |
|---|---|
| Economics | Calor cost per correctly accepted change: one-sided 97.5% upper ratio bound <= 0.50 versus BOTH ordinary C# and strong protected C# |
| Completion | One-sided 97.5% lower correctly accepted fraction >= 80%; differences versus each control >= -5 percentage points |
| Safety | One-sided 97.5% upper serious-defect differences <= +1 percentage point, over BOTH all-assigned and accepted denominators |
| Trust/adoption | No confirmed false-established property or accepted unauthorized bypass; successful independent adopter handoff within the registered scope |

Allocate alpha = 0.025 to each positive decision branch; all components in a branch must pass (intersection-union). The union bound controls any false-positive branch claim at 5%, not simultaneous interval coverage. Workflow-only requires B's same full adoption gates versus A while C does not earn continuation; INVALID takes precedence.

**No risk-margin relaxation is proposed.** A different claim requires a separate written business-risk rationale, adopter acceptance, independent methods review, and owner approval before a comparative pilot. Affordability alone is not justification.
