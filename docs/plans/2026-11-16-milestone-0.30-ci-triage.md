## Decisions (stated conflict → recommendation → proceeding on it)

- **D1. Rows on constructors, accessors and static initializers.** The 2026-11-14 decision
  lets any callable write `! unknown`, and the converter writes it instead of preserving
  the file. Constructors, accessors and implicit static initializers cannot carry a row,
  so Calor0422 still forces whole-file preservation. *Recommendation:* allow `! unknown`
  on constructors and accessors, and charge an implicit static initializer to the type's
  static constructor row so the converter can declare it. Do not relax the certification
  compile (its comment requires checked output). This fixes R1 at the source.
- **D2. Omitted callback row.** Calor0407 makes an omitted callback row a hard error.
  The 2026-11-10 note says "Accept Unknown"; `calor_help` says "omission means Unknown".
  *Recommendation:* keep the error (it matches Calor0124 for boundaries and the explicit
  `! unknown` decision) and fix `calor_help` and the 14 tests.
- **D3. Manifest name fallback for types absent from referenced metadata** (`ILogger`,
  `DbContext`, `Enumerable` without `System.Linq`). *Recommendation:* no fallback;
  rewrite the 4 tests with references and valid C# shapes. Name-only lookup was the
  unsound path 0.29 removed.
- **D4. Collection element type checks** (`new List<int>(){1,"x"}`) now only fail in
  Roslyn validation (Calor1002). *Recommendation:* accept Roslyn as the backstop, delete
  the 9 `TypeCheck_*` tests.
- **D5. `calor-first-guard`.** 19 new `.cs` paths (17 in `tools/Calor.LegacySyntaxRewriter/`,
  plus `Analysis/ContractFixEdit.cs` and `LanguageServer/Utilities/NativeCallContext.cs`)
  are not on main's allowlist; a PR cannot exempt itself. **Decided (maintainer,
  2026-11-16): delete the one-off rewriter tool and fold the two product classes into
  their callers' existing files.** Done in `608dfd21d`; no new C# paths remain.
- **D6. Website landing test** requires mounted Calor snippets, but `<FeatureGrid>` has
  not been mounted since #1352. *Recommendation:* relax the test to allow zero mounted
  snippets and keep the unregistered-code guard.
