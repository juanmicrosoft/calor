# 0.30 syntax spelling decision (#1597)

**Rule (maintainer, 2026-10-20):** every 0.30 spelling choice goes to the variant with the fewest tokens, not the most readable one.

**Ties:** when two or more variants tie exactly, pick (1) the C# spelling, then (2) the probe baseline, then (3) the fewest UTF-8 bytes. Rows decided this way are marked *tie*.

**Measurement.** Claude Opus 5.5 (`GET /v1/models` → `claude-opus-5-5`), `/v1/messages/count_tokens` only, 367/400 HTTP attempts, no generation. Run [41665665387](https://github.com/juanmicrosoft/calor/actions/runs/41665665387); tool `main` 2ce8a9c (`count_tokens.py` `5d34e62f…`); payload ce134ec (`inputs_sha256 7f8af24d…`, manifest `7c99c3b2…`, baseline source d82f3ae); `results.json` `606a125d…` (artifact 13246990894). Each count is one single-message `input_tokens` including fixed API framing, which cancels in deltas but dilutes small-probe percentages, so decisions use absolute deltas.

**Population and limits.** Primer 1; converted 20 (6 MediatR, 6 Serilog, 6 FluentValidation, 1 Synthetic, 1 Synthetic2: a hand-picked declaration-heavy convenience sample, not the 283-file census); 20 historical run-1 agent files from fewer than 20 independent tasks. Population variants bundle sigils, braces, typed-literal removal and expressions; probe savings overlap and do not add. Non-baseline payloads are speculative hand-written text, not compiler-accepted syntax or runtime-equivalence evidence.

## Chosen grammar (measured parts only)

```text
module M
  class C                                  // public default; lowercase keywords, no sigil
    func Add (int:a, int:b) → int          // type:name, C# types, T[] / T?
      ! cw                                 // effects; `=> e` = postcondition
      var int:n = a + b                    // mutable; `let` = immutable
      set n n + Make().B()[I()].M(Arg())   // infix, C# precedence, any expression as callee
      do
        set n Read()
      while n < 0
      return "v=${n,4:D2} lit=\${0}"       // plain string: ${…} runtime hole, \${…} literal
  raw delegate <N>                         // <N> = exact UTF-8 byte count of the payload below
public delegate void D();
```

## Consequences

- **Ambiguity.** Infix with C# precedence removes greedy `§C` absorption and the `§/C`, `§/NEW`, `§/LAM` closers; `f()`/`(f)`/`(f, x)` follow C#; the ~45 builtin heads and word operators cannot capture calls, collisions use `@name`. `M<T>(x)` needs C# type-argument lookahead then `(`. Implication `->` is gone (no clash with `→`). `!`/`=>` are header clauses only before the first body statement; lambdas keep `=>` in expressions. `var` means mutable, not inferred; `let` and `var` both infer an omitted type. Interpolation A migrates literal digit placeholders (`${0}` → `\${0}`).
- **Call target.** `CallExpressionNode.Target:string` becomes an expression callee with ordered arguments. BCL identity comes from the bound receiver `RoslynSymbol` plus the Roslyn-selected method and argument mapping, never spelling; `MetadataArrayResultType`/`ResolvedMetadataMethod` (997aa02) must flow through.
- **Hoist.** Converter `_new`/`_chain`/`_elem`/`_idx` temporaries become unnecessary; the sample's one `_chain` hoist stayed in the infix payload, so its removal is unmeasured. Emitter temporaries must keep left-to-right evaluate-once order and never lift out of `&&`, `||`, `?:` operands.
- **Interop.** C# type/array/nullable spellings remove the name mapping. `raw <reason> <N>` carries exact bytes (CRLF, no final newline, delimiter text, inactive malformed branches) regardless of indentation, never base64; `<N>` is the exact UTF-8 length, computed by the converter. Only a delegate stays raw in this sample.

## Remaining decisions and gaps

1. **Counted loops.** #1606 requires one counted-loop construct. Row 12 compares header layouts only, inside two speculative keywords. The unified keyword is **unmeasured and undecided**: no probe compares `range` vs `for` or a shared keyword. Separately, its snapshot vs re-evaluated semantics need an explicit representation (#1599).
2. **Documentation tags.** #1596 allows `///` comments or one doc tag.
   - Per probe, `@`-doc wins `since` (34 vs 35), and the `§`-tagged body form wins deprecated, deprecated-no-replacement and breaking.
   - A sigil-free body tag was not measured, so it is not a winner.
   - Among `///` forms, `@`-doc is fewest in all 4 probes.
3. **Weak decisions.** Rows decided by *tie*. `→` and `func` win by 1 token each, in one context only.
4. **Unmeasured** (no choice made):
   - indexed store/upsert and the two-name foreach (local supplement `5bc7bb7c…`, unpublished);
   - typed-literal removal on its own;
   - `[int]` with C# names;
   - hoist-free converter output;
   - #1622 defaults: `match` vs `if` chain (3+ constants), conditional expression vs assigning `if`, LINQ vs loops, counted loop vs `while`.
5. **Native record declarations.** Native record declaration spelling is **unmeasured**. The old `§D` is retired and fields-only. This gates faithful acceptance of the 044/100 native cases.
6. **Semantics.** Token counts do not establish meaning. Loop semantics, native `do`, upsert-not-`Add` and evaluate-once stores need acceptance tests from their owners.
