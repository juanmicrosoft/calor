# 0.30 syntax spelling decision (#1597)

**Rule (maintainer, 2026-10-20):** every 0.30 spelling choice goes to the variant with the fewest tokens, not the most readable one.

**Ties:** where variants tie exactly, the choice goes to (1) the C# spelling, then (2) the probe baseline, then (3) the variant with fewer UTF-8 bytes. Every tie is marked `tie` in the table below.

**How to read the counts.**
- Each count is the `input_tokens` for one independent single-message request, so it includes a fixed per-request API framing overhead.
- The framing cancels in a delta between variants, but it dilutes probe percentages. Decisions therefore use absolute deltas.

**Populations.**
- 1 primer.
- 20 converted files: 6 MediatR, 6 Serilog, 6 FluentValidation, 1 Synthetic, 1 Synthetic2. This is a hand-picked, declaration-heavy convenience sample, not the 283-file census.
- 20 historical agent files, all run 1, from fewer than 20 independent tasks.

**What the population numbers do and don't mean.**
- The population variants bundle many changes at once: sigils, braces, typed-literal removal and expressions.
- Probe savings overlap, so they don't add up.
- Non-baseline payloads are hand-written design text. They are not accepted compiler syntax and not evidence of runtime equivalence.

## Chosen grammar (0.30 target)

```text
module M
  class C                                   // public by default; tokens are lowercase, no sigil
    func Add (int:a, int:b) → int           // type:name, C# types, T[] and T? forms
      ! cw                                  // effects; `=> e` is a postcondition
      var int:n = a + b                     // mutable; `let` is immutable
      set n n + Make().B()[I()].M(Arg())    // infix, C# precedence, any expression as call target
      range i from A() to B() step S()      // snapshot: inclusive, evaluated once (current §L)
        Use(i)
      for i = A(); i < N(); i = i + 1       // C# counted loop: condition re-evaluated
        Use(i)
      do
        set n Read()
      while n < 0
      return $"v={n,4:D2} lit=\${0}"        // ${…} is always runtime; \${ is literal
  raw delegate 27                           // raw <reason> <UTF-8 byte count>, then exact bytes
public delegate void D();
```

## Consequences

**Ambiguity.**
- All expressions are infix with C# precedence. This removes greedy `§C` absorption and all `§/C`, `§/NEW` and `§/LAM` closers.
- Grouping, zero-argument calls and tuples follow C# exactly.
- The roughly 45 case-folded builtin heads and the word operators can't capture user calls, because calls are no longer prefix forms. A user identifier that collides with a keyword is written `@name`.
- `M<T>(x)` needs C#'s generic-versus-less-than disambiguation (type-argument-list lookahead followed by `(`).
- `->` implication is gone; it never collides with `→`.
- `!` and `=>` are header clauses only before the first body statement. Lambdas keep `=>` in expression position.
- `var` means *mutable*, not "inferred type". Both `let` and `var` infer their type when the type is omitted.

**Call target.**
- `CallExpressionNode.Target:string` becomes an expression callee or receiver, with ordered arguments.
- BCL identity comes from the bound receiver type's `RoslynSymbol` plus the Roslyn-selected method and argument mapping, never from the spelling.
- The `MetadataArrayResultType` / `ResolvedMetadataMethod` facts (997aa02) must flow through the new node.

**Hoist.**
- The converter's `_new`, `_chain`, `_elem` and `_idx` temporaries become unnecessary. The only hoist in this sample, `_chainHandlerCallback005` in MediatR ForeachAwaitPublisher, was kept in the infix payload, so removing hoists would save more tokens than measured here.
- The emitter may still introduce temporaries, but they must keep left-to-right, evaluate-once order and must never be lifted out of `&&`, `||` or `?:` operands.

**Interop.**
- C# type, array and nullable spellings remove the Calor-to-C# name mapping.
- `raw <reason> <bytes>` carries exact bytes (CRLF, no final newline, delimiter text, inactive malformed branches) independent of indentation. It is never base64.
- Writers must count UTF-8 bytes exactly; the converter emits the count.
- In the sample, only a delegate declaration stays raw.
- Interpolation choice A requires migrating every literal digit placeholder `${0}` to `\${0}`.

## Genuine remaining decisions and gaps

1. **Ties (rows 8, 11–13, 16–18, 20)** were decided by the tie-break rule, not by tokens.
   - The `→` (−1) and `func` (−1) margins are single tokens in a single context.
2. **Not measured; no choice made:**
   - indexed store or dictionary-setter upsert, and the two-name foreach header (local supplement `inputs_sha256 5bc7bb7c…`, unpublished);
   - typed-literal prefix removal on its own (it is bundled into rows 1–3);
   - `[int]` with C# names;
   - the hoist-free converter output.
   - the #1622 canonical-usage defaults. The approved report has no paired probe for any of them, so all four stay proposed rules, not measured winners:
     - `match` vs `if` chains for 3 or more constant cases;
     - a conditional expression vs an assigning `if`;
     - LINQ vs loops;
     - a counted loop vs `while`. Row 17 compares two `for` spellings, not `for` against `while`.
3. **Structured documentation (row 28).**
   - The existing body tags cost the fewest tokens, but their sigil-free head spelling was not measured.
   - If the tags must move into `///` comments, the `@` form is fewest among the comment forms in all 4 probes.
   - The owner must still decide between keeping the tags and moving them.
4. **Semantics.** Token counts do not establish meaning.
   - The `range` and `for` semantics, native `do`/`while`, upsert-not-`Add`, and evaluate-once indexed stores must each be accepted by the implementation owners' own tests.
