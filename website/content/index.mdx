Calor is an experimental programming language for teams that use AI coding
assistants to build .NET software. It helps make important rules for a change
easier to see and check. Calor can also create regular C# code, so teams can
use their familiar .NET build and test tools.

Calor does **not** guarantee that software is free of bugs. Its checks cover
specific, documented cases; people still need to review changes and run tests.
You can try Calor without connecting an AI assistant.
