Start the Calor Language Server using the standard input/output transport.

```bash
calor lsp
```

Editors and integrations launch this long-running process and communicate with
it using the Language Server Protocol. Do not write other output to its stdio
stream. Point your editor's LSP client at this command; see the
[installation page](/docs/getting-started/installation/) for the current
extension distribution status.
