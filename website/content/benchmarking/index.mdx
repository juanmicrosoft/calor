The historical dashboard covers **217 source pairs across eight
deterministic metrics**, with **30 repetitions**. Its recorded source revision
`3a452b09` declares compiler `0.19.0`; the executed binary was not independently
recorded. It reports a 1.32x legacy Calor/C# static-score composite.
The pairs are not all behaviorally equivalent, and the reported intervals do not
establish independent sampling uncertainty. These scores cannot establish a
language or coding-agent advantage. Read the
[snapshot provenance and limits](/docs/benchmarking/results/#read-the-results-carefully).
The [research evidence status](/docs/benchmarking/evidence-status/) records why
the 0.20 planning tranche stopped without a scientific verdict or software
release.

## The Metrics

### Published Metrics

The names below identify calculator rules, not observed agent abilities:

| Static metric | Calculator input or rule |
|:--------------|:-------------------------|
| [Comprehension](/docs/benchmarking/metrics/comprehension/) | Structural and semantic signals |
| [Correctness](/docs/benchmarking/metrics/correctness/) | Static correctness signals |
| [Edit Precision](/docs/benchmarking/metrics/edit-precision/) | Heuristic targetability and change isolation |
| [Error Detection](/docs/benchmarking/metrics/error-detection/) | Explicit detection signals |
| [Generation Accuracy](/docs/benchmarking/metrics/generation-accuracy/) | Compilation and structural signals |
| [Information Density](/docs/benchmarking/metrics/information-density/) | Counted semantic elements per token |
| [Refactoring Stability](/docs/benchmarking/metrics/refactoring-stability/) | Reference preservation under modeled transformations |
| [Token Economics](/docs/benchmarking/metrics/token-economics/) | Composite of token, character, and line ratios |

The repository also contains separate LLM and estimation-mode suites for
[task completion](/docs/benchmarking/metrics/task-completion/),
[safety](/docs/benchmarking/metrics/safety/), and
[effect discipline](/docs/benchmarking/metrics/effect-discipline/). Their
results are not included in the eight-metric headline or the 1.32x composite.

## Static Score Ratios

<BenchmarkSummaryTable />

Ratios above 1 indicate a higher Calor calculator score; below 1 indicate a
higher C# score. They are not measurements of language quality. The token
economics composite must not be read as a raw-token saving. Use the
[dated source, method, and limitations](/docs/benchmarking/results/#read-the-results-carefully)
when interpreting any row.

## Agent Task Benchmark

The [Agent Task Benchmark](/docs/benchmarking/agent-tasks/) reports a separate
historical prompt-to-code artifact. Its pass/fail results are not static
calculator scores and are not part of the dashboard composite. That page
records its date, task denominator, method, and missing provenance.
