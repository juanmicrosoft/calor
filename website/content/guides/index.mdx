Practical help for using Calor in a .NET project. If you are new to Calor,
start with [a small example](/docs/getting-started/hello-world/) first. The
guides below cover specific tasks and some assume you already use .NET.

---

## Available Guides

### [Nullability and .NET Interop](/docs/guides/nullability-and-dotnet-interop/)

How Calor handles values that may be missing when they cross between Calor and
.NET code.

### [Adoption Playbook](/docs/guides/adoption-playbook/)

How to try Calor gradually, understand what its checks do not cover, and keep
the option to return to regular C#.

### [Verification Guarantees and Limits](/docs/guides/verification-guarantees/)

What Calor's different check results mean, which cases it cannot decide, and
why a successful check is not a guarantee that a whole program is correct.

### [Project Intelligence for Agents](/docs/guides/project-intelligence-for-agents/)

For developers and coding agents: find what calls a piece of code and what a
change may affect before editing it.

### [Converting C#: What Stays C# and Why](/docs/guides/csharp-interoperability/)

For developers moving existing C# code: see which code Calor can convert,
which parts stay in C#, and how to review the conversion report.

### [Adding Calor to Existing Projects](/docs/guides/adding-calor-to-existing-projects/)

Step-by-step help for adding Calor to an existing C# project without moving
everything at once.

### [Dependent Types Tutorial](/docs/guides/dependent-types-tutorial/)

An advanced tutorial on describing extra rules about values and asking the
verifier to check them. It assumes familiarity with programming.

### [Effect Manifests: .NET Ecosystem Coverage](/docs/guides/effect-manifests-dotnet-ecosystem/)

For developers integrating external libraries: how Calor looks up what those
libraries can do and how to add missing information.

### [Cross-Assembly IL Analysis](/docs/guides/il-analysis/)

For developers: how Calor examines compiled .NET libraries to learn what
actions their code can perform, and where this analysis has limits.

### [Cross-Module Effect Propagation](/docs/guides/cross-module-effect-propagation/)

For developers: how Calor checks that action declarations stay consistent
across multiple files, including its warnings and build behavior.

### [Telemetry and Privacy](/docs/guides/telemetry/)

What information Calor sends when optional usage reporting is enabled, and
what it does not collect.

---

## Getting Started

If you're new to Calor, start with the [Getting Started](/docs/getting-started/) section instead. These guides assume familiarity with Calor basics.
