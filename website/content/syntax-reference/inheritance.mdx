Calor supports object-oriented inheritance with abstract classes, virtual methods, and interface implementation.

---

## Class Modifiers

Classes can be marked with modifiers to control inheritance behavior.

### Syntax

```calor
§CL{Name:modifiers}
  // class body
```

> **Note:** Class headers start with the class name, followed by any visibility or modifiers. Visibility defaults to public. Declaration identity belongs in `.calor/ids.json`, not in the header.

### Modifiers

| Modifier | Meaning |
|:---------|:--------|
| `abs` | Abstract class - cannot be instantiated |
| `seal` | Sealed class - cannot be inherited |
| `stat` | Static class - all members must be static |
| `partial` | Partial class - split across files |

### Examples

**Abstract class:**
```calor
§CL{Shape:abs}
  §MT{Area:pub:abs}
    §O{double}
```

**Sealed class:**
```calor
§CL{FinalService:seal}
  §MT{Process:pub}
    §O{void}
```

**Static methods** (static class modifier not fully implemented):
```calor
§CL{MathUtils:pub}
  §MT{Square:pub:stat}
    §I{i32:x}
    §O{i32}
    §R (* x x)
```

## Inheritance Declaration

### Extending a Class (`§EXT`)

Use `§EXT{ClassName}` to inherit from a base class.

```calor
§CL{Circle:pub}
  §EXT{Shape}
  §FLD{f64:_radius:priv}
  // ...
```

**Generated C#:**
```csharp
public class Circle : Shape
{
    private double _radius;
}
```

### Implementing Interfaces (`§IMPL`)

Use `§IMPL{InterfaceName}` to implement interfaces. Multiple interfaces can be implemented.

```calor
§CL{GameObject:pub}
  §IMPL{IMovable}
  §IMPL{IDrawable}
  §MT{Move:pub}
    §O{void}
  §MT{Draw:pub}
    §O{void}
```

**Generated C#:**
```csharp
public class GameObject : IMovable, IDrawable
{
    public void Move() { }
    public void Draw() { }
}
```

### Combined Inheritance

```calor
§CL{Dog:pub}
  §EXT{Animal}
  §IMPL{IPet}
  §IMPL{ITrainable}
  // ...
```

**Generated C#:**
```csharp
public class Dog : Animal, IPet, ITrainable { ... }
```

## Method Modifiers

Methods support modifiers for polymorphism.

### Syntax

```calor
§MT{Name:visibility:modifiers}
  §O{returnType}
  // method body
```

### Modifiers

| Modifier | Meaning |
|:---------|:--------|
| `virt` | Virtual - can be overridden |
| `over` | Override - replaces base implementation |
| `abs` | Abstract - no implementation |
| `seal` | Sealed - prevents further override |
| `stat` | Static - belongs to the class |

### Virtual Methods

```calor
§CL{Animal:pub}
  §MT{Speak:pub:virt}
    §O{str}
    §R "..."
```

**Generated C#:**
```csharp
public class Animal
{
    public virtual string Speak()
    {
        return "...";
    }
}
```

### Override Methods

```calor
§CL{Dog:pub}
  §EXT{Animal}
  §MT{Speak:pub:over}
    §O{str}
    §R "Woof!"
```

**Generated C#:**
```csharp
public class Dog : Animal
{
    public override string Speak()
    {
        return "Woof!";
    }
}
```

### Abstract Methods

Abstract methods have no body and must be in an abstract class.

```calor
§CL{Shape:abs}
  §MT{Area:pub:abs}
    §O{double}
```

**Generated C#:**
```csharp
public abstract class Shape
{
    public abstract double Area();
}
```

### Sealed Override

Prevents further overriding in derived classes. Combine modifiers with spaces.

```calor
§MT{Compute:pub:seal over}
  §O{i32}
  §R 42
```

**Generated C#:**
```csharp
public sealed override int Compute()
{
    return 42;
}
```

## Base Calls

### Calling Base Methods

Use `base.MethodName` (lowercase) inside `§C{...}` to call the base class implementation.

> **Important:** Use `base.Method` not `§BASE.Method` inside call expressions.

```calor
§CL{Derived:pub}
  §EXT{Base}
  §MT{GetValue:pub:over}
    §O{i32}
    §R (+ §C{base.GetValue} §/C 5)
```

**Generated C#:**
```csharp
public class Derived : Base
{
    public override int GetValue()
    {
        return base.GetValue() + 5;
    }
}
```

### Base Constructor Calls

Use `§BASE §A args §/BASE` in a constructor to call the base constructor.

```calor
§CL{Dog:pub}
  §EXT{Animal}
  §FLD{str:_breed:priv}

  §CTOR{pub}
    §I{str:name}
    §I{str:breed}
    §BASE §A name §/BASE
    §ASSIGN §THIS._breed breed
```

**Generated C#:**
```csharp
public class Dog : Animal
{
    private string _breed;

    public Dog(string name, string breed)
        : base(name)
    {
        this._breed = breed;
    }
}
```

## Complete Example

Here's a complete example demonstrating inheritance with a Shape hierarchy.

### Base Class

```calor
§CL{Shape:abs}
  §FLD{str:_name:prot}

  §CTOR{prot}
    §I{str:name}
    §ASSIGN §THIS._name name

  §MT{Area:pub:abs}
    §O{double}

  §MT{Describe:pub:virt}
    §O{str}
    §R §INTERP §THIS._name " with area " §C{this.Area} §/C §/INTERP
```

### Derived Class

```calor
§CL{Circle:pub}
  §EXT{Shape}
  §FLD{double:_radius:priv}

  §CTOR{pub}
    §I{double:radius}
    §BASE §A "Circle" §/BASE
    §ASSIGN §THIS._radius radius

  §MT{Area:pub:over}
    §O{double}
    §R (* 3.14159 (* §THIS._radius §THIS._radius))
```

### Usage

```calor
§F{Demo:pub}
  §O{str}
  §B{shape:Shape} §NEW{Circle} §A 5.0
  §R §C{shape.Describe} §/C
```

## Quick Reference

| Task | Syntax | Example |
|:-----|:-------|:--------|
| Abstract class | `§CL{Name:abs}` | `§CL{Shape:abs}` |
| Sealed class | `§CL{Name:seal}` | `§CL{Final:seal}` |
| Public class | `§CL{Name:pub}` | `§CL{Service:pub}` |
| Extend class | `§EXT{BaseClass}` | `§EXT{Shape}` |
| Implement interface | `§IMPL{Interface}` | `§IMPL{IDrawable}` |
| Virtual method | `§MT{Name:vis:virt}` | `§MT{Speak:pub:virt}` |
| Override method | `§MT{Name:vis:over}` | `§MT{Speak:pub:over}` |
| Abstract method | `§MT{Name:vis:abs}` | `§MT{Area:pub:abs}` |
| Sealed override | `§MT{Name:vis:seal over}` | `§MT{Get:pub:seal over}` |
| Static method | `§MT{Name:vis:stat}` | `§MT{Create:pub:stat}` |
| Call base method | `§C{base.Method} §/C` | `§C{base.GetValue} §/C` |
| Call this method | `§C{this.Method} §/C` | `§C{this.Process} §/C` |
| Base constructor | `§BASE §A args §/BASE` | `§BASE §A name §/BASE` |

> **Note:** Static and partial class modifiers are not fully implemented. Use static methods within regular classes.
