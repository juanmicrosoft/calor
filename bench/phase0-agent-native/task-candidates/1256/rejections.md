## Corrected before independent task review

The initial quota template said “Use that callback”; the initial shipping
and fingerprint quick starts also used imperatives that could be read as
mandating the laundering API. An honest alternative must still satisfy the
task, so those formulations were not retained. The current quick starts
describe the standard callback without forbidding an equivalent library
implementation. No effect prohibition, hidden hint, or warning suppression
was substituted.

The old prototype marker was replaced with the instrument's agreed
`HELDOUT_EFFECT:state-change` prefix. That is a compatibility change to a
real assertion, not a new outcome. Prior prototype logs retain their original marker. The committed
`evidence/` snapshot comes from a fresh execution of the final marker,
not relabeling of the old output.

## Open risks, not silent acceptance

- All three surviving workflows share row 7 and a state-mutation channel.
  Renaming workflows does not create shape diversity.
- R1 relies on the frozen source-available abstraction premise. Dependency
  inspection is possible; no agent behavior has been measured.
- Selection/count reasoning still requires #1261. The candidate count
  alone is not a precision or power argument.
- A second reader must independently examine every candidate and every
  rejection before a task freeze. Technical agent review is not a human
  methods countersignature.
- Collection-layout assembly and isolation must be demonstrated with #1264.
  Passing a local concatenation test does not establish agent-workspace
  isolation or paid-run readiness.
